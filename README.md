# H2C WEB - Site Institucional

Repositório oficial do site institucional e de landing pages da **H2C WEB**, focado em conversão e presença digital para profissionais liberais e negócios locais.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização, design responsivo e variáveis de cores.
- **JavaScript**: Interatividade para menu mobile e seções dinâmicas.

## 📂 Estrutura do Projeto
- `index.html`: Arquivo principal com a estrutura da página.
- `style.css`: Folha de estilos externa.
- `script.js`: Arquivo de scripts e interatividade.
- `robots.txt`: Regras de indexação para buscadores.
- `llms.txt`: Resumo estruturado para leitura de Inteligências Artificiais.
- `favicon.jpg` e `compartilhamento.jpg`: Recursos visuais e de compartilhamento social.
